## **Project Description**  
C.A.B. is my first-ever project, built to tackle the pressing issue of cybersecurity awareness in organizations. Human errors are a leading cause of cyber breaches, and this bot aims to address that by delivering timely, interactive messages on Slack.  

The bot sends weekly **security tips**, conducts **phishing simulations**, and posts **quiz questions**, all designed to foster a proactive cybersecurity culture in workplaces.

---

## **What Does the Bot Do?**  
C.A.B. covers three core aspects of cybersecurity training:

1. **Weekly Cybersecurity Tips**  
   Clear and practical advice shared every Monday to improve awareness.  

2. **Phishing Simulations**  
   Safe and realistic phishing tests to measure alertness, delivered every Wednesday.  

3. **Quiz Questions**  
   Engaging quizzes shared every Friday to make learning fun and memorable.

---

## **How It Works**  

1. **Programming Logic**  
   - Written in Python using `slack_sdk` and `schedule` libraries.  
   - Modular code for simplicity and future scalability.  
   - Developed and tested in **Visual Studio Code**.  

2. **Organized Workflow**  
   - Project folder structure designed for clarity and easy updates.
   - Version-controlled using GitHub for collaboration and transparency.
